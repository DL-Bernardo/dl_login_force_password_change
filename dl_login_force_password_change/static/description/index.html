🔐 DL Force Password Change on First Login

Enforce enterprise-grade cybersecurity governance in your Odoo instance. Obligate newly created internal users to set their personal password upon first login, trigger instant resets on-demand, and enforce periodic expiration policies.

🚀 Key Security Capabilities

Zero external dependencies, seamless Odoo 17 integration, and instant protection.

🔑

First-Login Mandatory Reset

New internal users are systematically required to establish their private password before gaining access to any corporate ERP data.

⚡

One-Click Admin Reset

Administrators can mark any user with "Force Password Change on Next Login" or click "Force Now" directly from the user form.

⏱️

Periodic Expiration Policy

Includes an automated background cron job that regularly flags accounts past the maximum age policy (configurable, default 11 months).

🛡️

Real-Time Complexity Check

Visual verification rules: minimum 8 characters, uppercase letter enforcement, number/symbol checks, and password match confirmation.

🌐

Glassmorphic Security Portal

A modern, distraction-free security portal that prevents navigation bypass and session tampering until the password is updated.

🕒

Audit & Compliance Trail

Displays the exact timestamp of the user's last password change directly in their Odoo user preferences card.

📸 Step-by-Step Visual Walkthrough

See exactly how the module functions in live operation.

Step 1

Administrator Configures User Security

Navigate to Settings > Users & Companies > Users. Under the Password Security section, activate "Force Password Change on Next Login" or click "Force Now".

Step 2

User Logs In With Temporary Credentials

The user enters their email address and initial/temporary password on the standard Odoo login screen.

Step 3

Automatic Interception & Real-Time Validation

The system immediately halts normal navigation and presents the Digitalub Password Security Portal. Dynamic validators check length, uppercase letters, and flag password mismatches instantly.

Step 4

All Security Requirements Satisfied

When all criteria are met (green checkmarks for length, uppercase, numbers/symbols, and match), the "Update Password" action button becomes active.

Step 5

Re-Authentication With New Credentials

The user logs in with their newly verified personal password.

Step 6

Secure Access Granted & Audit Logged

The user lands safely in their personalized Odoo workspace. The mandatory change flag is cleared, and the last password update timestamp is recorded.
